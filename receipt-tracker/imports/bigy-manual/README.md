# Big Y Manual Import Inbox

Put manually downloaded Big Y receipt files here before processing.

Suggested file types:
- .png
- .jpg / .jpeg
- .pdf
- .txt (only when paired with the original receipt image or PDF)

Suggested workflow:
1. Copy one receipt file into this folder
2. Upload it in the local app at http://127.0.0.1:8000/upload
3. Review extracted fields and line items
4. Use OpenClaw suggestions for review-needed items
5. Move handled files into ../processed if desired

Keep originals.
