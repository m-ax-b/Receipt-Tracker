Supported file types include .jpg, .jpeg, .png, .webp, .bmp, .gif, .tif, .tiff, .pdf, .html, and .htm.

How routing works

  • The router inspects the uploaded object instead of asking the user to pick a parser.
  • Known structured sources, like BJ's saved HTML, go to deterministic adapters before any AI escalation.
  • Receipt images stay on the OCR-first path.
  • All supported uploads still land in canonical artifact packages under data/artifacts/.

This keeps the human-facing upload UX simple while letting new parsers, connectors, and evidence adapters plug into the same governed loop later.
